# Infinite Paper v1.5.0

- 新增钢笔、铅笔、圆珠笔、毛笔、秀丽笔五种独立笔尖效果。
- 激光笔现在实时跟随书写，并在三秒内平滑渐隐；再次书写会让未消失轨迹重新计时。
- 书架新增全部笔记、我的收藏、已加锁笔记、最近删除、搜索、封面、收藏/加锁/恢复等本机管理功能。
- “新建或导入”提供新建笔记、命名文件夹入口、图片导入及 PDF 本机附件入口。
- 导出 PNG 与编辑器统一图层顺序、图片旋转、文本样式及奶白背景；编辑器图片缓存增加尺寸限制与释放策略。

验证：`flutter test` 24/24 通过；`flutter analyze` 无 error（保留既有风格级 info）。
