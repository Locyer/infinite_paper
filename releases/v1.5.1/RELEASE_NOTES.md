# Infinite Paper v1.5.1

- 缩小 HSV 色板和选区换色面板，工具设置不再占据过大空间。
- 套索选区、图片、文本在移动后，轻点选中区域可重新显示操作条；套索操作改名为“调整大小并移动”。
- 选区换色使用与画笔一致的快速色板与 HSV 自定义色，文本颜色也走相同入口；操作条提供复制、剪切和删除。
- 文件夹为真实本机书架项目：可新建、重命名、删除（笔记会回到书架）以及将笔记移入/移出文件夹。
- 加锁笔记需设置至少四位密码；打开、管理或取消锁定前必须输入正确密码。
- 宽屏书架改为固定左侧栏，笔记标题和更多菜单移至封面下方，不会被封面遮挡；手机仍使用抽屉侧栏。

验证：`flutter test` 27/27 通过；`flutter analyze` 无 error（仅保留项目风格级 info）。
