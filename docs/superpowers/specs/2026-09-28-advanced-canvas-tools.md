# 无限草稿纸：高级工具设计

## 目标

在完全离线、JSON 本地保存的前提下，将现有无限画布升级为适合触控笔记的编辑器：触控笔优先、局部橡皮、套索、富色板、笔记首页、图片/文本、荧光笔、临时激光笔和更大缩放范围。

## 关键决定

- 文档继续保存世界坐标，不创建无限位图。缩放限定为 `0.001x–15x`；这是受双精度和屏幕像素约束下实际可用的“无限缩小”。
- `Stroke` 扩展为普通笔、荧光笔。激光笔仅存在内存，离笔后三秒淡出，不写入 JSON。
- 文档新增 `images[]` 与 `texts[]`。插入图片复制到应用文档目录，JSON 只记录本地路径。
- 局部橡皮通过圆形擦除轨迹分割笔画，产生的替换操作作为一个撤销步骤。
- 套索用世界坐标多边形命中对象；选中对象可删除、复制、剪切、统一缩放并改色。图片不改色。
- 输入模式支持“笔和手指书写”“仅触控笔书写，手指平移”“手指平移”；触控笔检测使用 `PointerDeviceKind.stylus`。
- 工具按钮双击或长按打开对应的颜色/粗细面板；完整 HSV 色板用于任意颜色，常见色作为快捷色。
- 首页为全部笔记列表，编辑页顶部可以返回首页或从菜单切换笔记。

## 性能与兼容

- 完成笔画与活动笔画使用独立 `RepaintBoundary`；笔画 Path 缓存。
- 画布按可视世界矩形裁剪；网格动态选择间隔并限制网格线数量。
- Android 16 使用 compileSdk/targetSdk 36；图片从系统相册选择，导出仍直接保存默认相册。
