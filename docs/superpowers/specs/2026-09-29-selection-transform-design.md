# Selection Transform Design

## Goal

将 Infinite Paper 的选择交互拆为两套明确行为：图片/文本/单个对象使用完整变换框；自由套索保持用户手绘边界并只对圈内内容操作。

## User-facing behavior

1. 点底部图片或文本按钮后，编辑器进入 `select` 工具；点击可命中的图片或文本立即选中，点击空白则平移画布。
2. 单对象选中后只显示一个整体框。四角和左、上、下中点是缩放柄；右中点是旋转柄；框旁边显示角度。
3. 选中框优先在对象上方显示操作条；空间不足时放在下方。操作条包含矩形裁剪、自由裁剪、复制、剪切、删除。文本不显示裁剪项。
4. 拖动对象内部移动对象；拖动缩放柄改变选框和对象尺寸；拖动旋转柄围绕当前对象中心旋转。距离 0/90/180/270 度不超过 4 度时吸附。
5. 套索结束后保持原始闭合路径，所有命中的内容只以一个选择状态呈现，不再按笔画绘制多个小框。删除、复制、剪切作用于套索内内容。
6. 套索操作条额外提供“调整大小”。触发后，以套索命中内容的外接矩形进入与对象相同的移动/缩放/旋转框；在该操作前不改变用户绘制的路径。

## Architecture

- `CanvasController` 维护 `SelectionPresentation`：`object`、`lassoPath`、`transformBox`；选择集合仍是统一的对象 ID 集合。
- `TransformHandle` 表示命中部位；控制器提供一次手势一个撤销步骤的移动、缩放与旋转会话。
- `InfiniteCanvas` 负责将世界坐标选择框映射到屏幕、命中控制柄、根据手势调用控制器，并以单一 overlay 绘制框、路径、角度和浮动操作条。
- 对象裁剪采用非破坏式矩形裁剪字段；自由裁剪在本版本以用户可绘制裁剪路径并裁剪显示为目标，若图片解码不支持则保持源图并保存路径。

## Constraints

- Flutter 3.x / Dart；所有内容离线保存在现有 JSON 文档。
- 不创建无限位图；所有交互继续使用世界坐标与当前 `Viewport`。
- 笔画、图片与文本的移动/缩放/旋转必须可撤销，拖动过程只能产生一条历史记录。
- 不新增后端、登录、广告或分析依赖。

## Validation

- 单对象选择只保留一个 selectionBounds，不按笔画分框。
- 移动、缩放、旋转、吸附角度和套索转变换框均有控制器测试。
- `flutter test` 全绿；`flutter analyze` 无 error。
