# 无限草稿纸 v1.2.0：对象编辑与书架首页设计

## 目的与验收

将个人离线草稿纸升级为更接近参考图的手写工作台：触控笔写字时手指可始终平移；可直观看到橡皮大小；图片、文本和套索选区均能被选中、缩放、旋转及操作；首页以书架卡片展示所有笔记。

## 输入与工具

- 触控笔和手指不再互斥。开启“手指移动”后，触控笔（`stylus`）继续使用当前书写/橡皮/套索工具，单指触摸始终平移视图；双指继续缩放或平移。
- 普通笔、荧光笔、激光笔保留颜色与大小。整笔/局部橡皮仅显示大小设置，不显示颜色控件。
- 橡皮在画布上显示跟随指针/笔尖的圆形轮廓，直径等于世界橡皮尺寸乘视图缩放；指针离开画布即隐藏。所有大小滑块旁显示同尺寸预览圆。
- 底栏不再单独显示无实际作用的颜色按钮；颜色仅在画笔、荧光笔、激光笔的配置面板中出现。

## 颜色面板

- 使用垂直色相条加二维饱和度/明度面板（HSV），与图 1 一致。
- 面板显示当前 HEX 值、取色圆点与快捷色。点击/拖动二维面板和色相条均实时更新当前颜色。
- 不引入网络或远程资源；色板通过 Flutter `CustomPainter` 在本地绘制。

## 对象选择、套索和变换

- 图片、文本和套索选中内容使用相同 `SelectionTransform`：中心、缩放、旋转角度、边界框。
- 首次插入图片/文本位置为当前屏幕中心所对应的世界坐标，固定初始尺寸。插入后立即选中。
- 点按图片/文本进入选择；选区显示虚线矩形、四角缩放柄、顶部旋转柄以及浮动操作条。
- 控制柄的拖动按中心固定方式缩放，旋转柄围绕选区中心旋转。此 MVP 支持统一缩放和旋转；文本和图片的矩形裁剪按钮先提供等比“裁剪到选区”入口，实际自由多边形像素裁剪列为 v1.3.0（需图像像素编辑器，超出本轮离线对象编辑范围）。
- 图片/文本操作条包含复制、剪切、删除、矩形裁剪、自由裁剪（提示后续）、层级保持；套索操作条包含复制、剪切、删除、调整大小、颜色。点击“调整大小”后套索虚线变为方形控制框，使用相同缩放/旋转柄。
- 旋转在 JSON 中保存为 `rotation`。画笔为点集合，套索对画笔应用几何变换；图片/文本直接保存矩形和旋转。

## 画布与数据

- `CanvasImage`、`CanvasText` 增加 `rotation`；旧 JSON 默认 `0`，保持兼容。
- 选择框与对象内容仍然在世界坐标绘制，绝不创建无限 Bitmap。
- 图片拖入应用私有目录继续保留；导出 PNG 使用对象矩形和旋转绘制。

## 首页

- 首页采用响应式“书架”：两列到四列笔记封面卡片，每张卡片为纸张缩略封面、标题、更新时间和更多菜单；第一张固定为新建笔记。
- 封面为本地 Canvas 绘制（网格、装订边、标题），不引入外部图片和内存大缩略图。

## 质量与发布

- Android/iOS 桌面显示名、应用标题和项目文档统一为 `Infinite Paper`；包名保持 `com.locyer.infinite_paper`，从而保留覆盖更新能力。
- Flutter 3.x、Android 16、iOS 保持支持；不增加后端、账号、广告、统计。
- 新增模型/控制器单测，所有 UI 改动后运行 `flutter analyze`、`flutter test` 与 `flutter build apk --release`。
- 版本升至 `1.2.0+3`，归档到 `releases/v1.2.0/`，提交并推送 Git，打 `v1.2.0` 标签。
